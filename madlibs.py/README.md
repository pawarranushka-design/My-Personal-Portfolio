# 🐍 Mad Libs Game

My first Python project!

## About the Project
Mad Libs is a fun word game where users enter adjectives, nouns, and verbs to create a funny story.

## Python Concepts Used
- Variables
- User Input (`input()`)
- Print Statements
- F-Strings

## How to Run
1. Install Python.
2. Open the terminal.
3. Run the following command:

```bash
python madlibs.py
```

4. Enter the words requested by the game and enjoy!
